# ComfyUI-H3-WorkflowHelper（H3 工作流助手）

ComfyUI MiniMax H3（首尾帧 / 口播 / 多段接力）工作流辅助插件。**纯前端辅助 + 一个纯透传节点**：所有按钮创建的都是 ComfyUI 内核官方节点，删除本插件后工作流仍是 100% 官方节点链。

## 功能

### 一、插入锚点按钮
在 `MiniMax H3 Image to Video` 和 `Add Guide for MiniMax H3` 节点上注入三个按钮：

- **＋ 插入参考图**：新建官方 `Add Guide` + `Load Image`，自动连好 positive / latent / vae
- **＋ 插入参考音频**：新建官方 `Add Guide` + `Load Audio`，自动连好 positive / latent / audio_vae
- **＋ 插入参考图和音频**：一个 AddGuide 同时锚定画面+音轨（接力锚点的官方形态）

frame_idx 自动填**段中点**；VAE 按文件名自动匹配视频/音频 VAE（找不到会自动新建，绝不静默接错）。

### 二、延长视频（接力新段）
段首节点上的 **＋ 延长视频（接力新段）** 按钮，一键追加一个完整接力段：

- **无论点的是哪个段的按钮，都自动从链条末段续接**——新段永远出现在画布最下面，不会插在中间
- 自动克隆整条段链（引导器 / 采样 / 双 VAE 解码 / 合成 / 保存）
- 自动创建接力桥：`Image From Batch`（batch_index = 上一段吸附后长度 − 22）+ `Trim Audio Duration`（−0.9167 秒 = 22帧/24fps）
- 长度自动按内核 17k+5 网格向上吸附（如输入 130 → 实际 141，桥值按 141 算）
- 每段自动配独立的 **Float (Duration) + 数学表达式** 时长链（按秒设定，自动吸附内核 17k+5 帧网格），与独立噪波（种子 = 上一段 + 1，接缝翻车可单摇）——各段时长互不影响
- 采样器 / 调度器全段共享（改步数全段一致）；新段语音锚点自动落在帧 22

### 三、删除段落（减段）
段首节点上的 **✂ 删除最后一段** 按钮（点任何段上的按钮都删链条最末段，与延长按钮同规则）：

- 自动识别整段节点集一键安全删除，共享节点（采样组件 / VAE / 分辨率选择器）绝不误删
- 可以一路删到只剩一段（只剩一段时按钮会拒绝并提示）
- 要删中间段：先删它之后的所有段再点延长重新生成（桥值会自动重算）

### 四、分组保护（GROUP 尊重模式）
图里一旦存在你手画的分组框，插件进入**分组保护模式**：

- 延长/删除/整理排版**都不会移动你分组框里的任何节点**——你的手工布局永远保留
- 新增段自动出现在**最下方分组框的正下方**（贴着往下长）
- 若被删的整段都在同一个分组框里，该空分组会一并清理
- 「⤓ 整理排版」只整理未分组的游离段；全部段都被你分组时会提示并保持原布局
- 删掉全部分组框即恢复自动排版行为

### 五、自动排版
- 追加/删除段落自动重排全图；也可随时点段首节点的 **⤓ 整理排版**
- 段带按**接力链条结构顺序**排列（首段在上，后继依次向下），段内按列分层："时长(Float+表达式) → 段节点+首尾帧 → 接力桥 → 锚点链+素材 → 引导器+噪波 → 采样 → 双解码 → 合成+保存"

### 六、分辨率统一管理
直接使用 **ComfyUI 官方 `Resolution Selector`** 内核节点（`分辨率=16:9`、`Megapixels=0.4`、`Multiple=32` 即 480P 档；官方全画质用 0.98MP），一处改动全段生效。「延长视频」生成的新段自动复制上一段的宽高来源，无需手动接线。

## 安装

```bash
cd ComfyUI/custom_nodes
git clone <本仓库地址>
```

重启 ComfyUI。无任何 Python 第三方依赖（仅需内核自带模块）。

## 配套工作流

仓库内的 `2026-09-04_H3分段视频工作流.json` 是与插件配套的模板（拖入 ComfyUI 即可导入）：默认只有段1，点「＋ 延长视频」按需增加段落：

- **B 档（默认激活）**：H3 专用 Sage 补丁 + EasyCache(0.15) + pytorch attention + 20 步——RTX 4080 上 864×480×124 帧实测 **150 秒**（基线 330 秒的 2.2 倍），20 步完整采样轨迹，口播/短剧通用
- **A 档（定稿）**：旁路 Sage + EasyCache，注意力后端切 comfy kitchen，建议 960×544 以上分辨率，出片配 SeedVR2 超分
- **C 档（草稿）**：启用 LoRA 槽位（turbo_4step_v1.0）与 TE-Speed（4-step LoRA 模式），步数改 4

## 环境要求

- ComfyUI ≥ 0.33（原生 MiniMax H3 节点），前端 ≥ 1.49
- MiniMax H3 FL2VA 权重 + Qwen3-VL 文本编码器 + 视频/音频双 VAE（见 [Comfy-Org/MiniMax-H3](https://huggingface.co/Comfy-Org/MiniMax-H3)）
- （可选，B 档加速）sageattention 2.x + triton（Windows: [woct0rdho/triton-windows](https://github.com/woct0rdho/triton-windows)）

## 故障排除

- **更新插件后按钮行为没变化**：前端可能缓存了旧的扩展代码。按 F5 普通刷新无效时，用 Ctrl+Shift+R 强制刷新，或浏览器设置里清除该站点数据后重开页面。
- **排版被自动重排**：图里只要存在你手画的分组框，插件就进入分组保护模式（不动你的节点）；全部删掉分组框即恢复自动排版。
